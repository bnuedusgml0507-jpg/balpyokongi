# 발표콩이 🐰

학생별 발표 횟수를 기록하는 핑크 동물 테마 앱입니다. 학생 1–11번과 31–42번, 총 23명을 관리합니다.

## 브라우저에서 바로 실행

GitHub Pages 웹 앱을 열면 설치나 ZIP 다운로드 없이 바로 쓸 수 있습니다. QR 코드를 스캔해도 같은 앱이 열립니다. 발표 횟수는 사용 중인 브라우저에 자동 저장됩니다.

## Windows 데스크톱 버전

`Balpyokongi.zip`을 내려받아 압축을 풀고 `Run-Balpyokongi.bat`을 실행합니다. 데스크톱 버전은 창을 닫으면 시스템 트레이로 숨고, 앱의 `완전히 종료` 버튼으로 끝낼 수 있습니다.

## 파일

- `index.html`: 브라우저용 앱
- `Balpyokongi.ps1`: Windows 데스크톱 앱
- `Run-Balpyokongi.bat`: 데스크톱 앱 실행
- `Balpyokongi.zip`: 데스크톱 앱 묶음
- `QR-발표콩이.png`: 브라우저 앱을 여는 QR 코드
